## 完整台北市租屋資料庫欄位結構（依優先順序排列）

### 第一優先級 - 核心篩選資訊

1. **房源名稱** (title)
2. **租金** (number)
3. **房型配置** (rich_text) - 幾房幾廳幾衛浴及公共空間
4. **坪數/室內面積** (number) - 精確的居住空間大小
5. **地址** (rich_text)
6. **Google Maps 地圖連結** (url) - 精確位置定位
7. **區域名稱** (rich_text)
8. **市區名稱** (rich_text)

### 第二優先級 - 關鍵決策因素

1. **照片** (files)
2. **樓層資訊** (rich_text) - 所在樓層/總樓層數
3. **入住日期** (date) - 可入住的最早時間
4. **押金（個月）** (number)
5. **水電費** (rich_text)
6. **管理費** (number) - 社區管理相關費用
7. **房東聯繫方式** (rich_text)

### 第三優先級 - 詳細規格與條件

1. **設備與特色** (multi_select)
2. **屋齡** (number) - 建築物年份，影響居住品質
3. **朝向** (select) - 採光與通風評估依據
4. **最短租期** (select) - 一年/半年/月租等選項
5. **寵物政策** (select) - 允許/不允許/限制條件
6. **性別限制** (select) - 男性/女性/不限
7. **身份限制** (multi_select) - 學生/上班族/外國人等

### 第四優先級 - 環境與交通

1. **最近捷運站** (rich_text) - 站名及步行時間
2. **交通便利性** (rich_text)
3. **生活機能** (rich_text)
4. **公共設施及空間** (multi_select)

### 第五優先級 - 補充資訊

1. **陽台數量** (number) - 戶外空間配置
2. **網路費用** (rich_text) - 是否包含及費用詳情
3. **仲介費** (rich_text) - 相關服務費用說明
4. **網頁連結** (url)
5. **網址** (url)

### 第六優先級 - 評估與管理

1. **適合度** (rich_text)
2. **平均評分** (number)
3. **重要優勢** (rich_text)
4. **看房狀態** (select)
5. **備註** (rich_text)
6. **其餘房源備註** (rich_text) - 額外補充說明
7. **簽約注意事項** (rich_text)
8. **更新日期** (date)

### 關於 Google Maps 整合說明

**地址欄位建議保持 rich_text 格式**，另新增獨立的「Google Maps 地圖連結」(url) 欄位，原因：

* 地址文字便於快速瀏覽與搜尋
* URL 欄位可直接嵌入 Google Maps 連結
* 兩者分離提供更佳的使用體驗與資料管理彈性

此結構優先展示租客最關注的核心資訊，再逐步提供詳細規格，最後補充管理用途的評估欄位。
