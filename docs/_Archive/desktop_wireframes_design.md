# 桌面版頁面線框圖設計規劃

## 整體佈局架構

### 頂部導航 (Top Bar)
- **Tab 1**: 房源搜尋 (Property Search)
- **Tab 2**: 數據分析 (Data Analytics) 
- **Tab 3**: 個人中心 (User Center)

### 隱藏式側邊欄 (Collapsible Sidebar)
- 預設收合狀態，點擊展開
- 包含詳細功能選單和快速操作
- 寬度: 收合時 60px，展開時 280px

### 主要內容區域 (Main Content Area)
- 響應式佈局，根據側邊欄狀態調整寬度
- 包含各Tab對應的功能模組

## Tab 1: 房源搜尋頁面

### 主要功能區塊
1. **搜尋篩選區** (Search & Filter Panel)
   - 地區選擇器
   - 價格範圍滑桿
   - 房型篩選
   - 進階篩選選項

2. **地圖視圖區** (Map View)
   - 互動式地圖
   - 房源標記點
   - 縮放控制

3. **房源列表區** (Property List)
   - 卡片式房源展示
   - 分頁控制
   - 排序選項

4. **房源詳情側欄** (Property Detail Sidebar)
   - 點擊房源後展開
   - 詳細資訊展示
   - 收藏功能

## Tab 2: 數據分析頁面

### 主要功能區塊
1. **儀表板概覽** (Dashboard Overview)
   - 關鍵指標卡片
   - 趨勢圖表
   - 快速洞察

2. **區域分析區** (Regional Analysis)
   - 熱力圖
   - 區域比較圖表
   - 統計數據表格

3. **趨勢預測區** (Trend Prediction)
   - 時間序列圖表
   - 預測模型結果
   - 信心區間顯示

4. **自定義分析區** (Custom Analysis)
   - 參數設定面板
   - 動態圖表生成
   - 報告匯出功能

## Tab 3: 個人中心頁面

### 主要功能區塊
1. **用戶資訊區** (User Profile)
   - 頭像和基本資訊
   - 帳戶設定
   - 偏好設定

2. **收藏管理區** (Favorites Management)
   - 收藏房源列表
   - 標籤分類
   - 批量操作

3. **搜尋歷史區** (Search History)
   - 歷史搜尋記錄
   - 快速重複搜尋
   - 搜尋偏好分析

4. **通知中心區** (Notification Center)
   - 系統通知
   - 價格變動提醒
   - 新房源推薦

## 隱藏式側邊欄功能架構

### 主要功能選單
1. **快速搜尋** (Quick Search)
2. **我的收藏** (My Favorites)
3. **最近瀏覽** (Recent Views)
4. **數據報告** (Data Reports)
5. **設定** (Settings)
6. **幫助中心** (Help Center)

### 快速操作區
- 新增搜尋條件
- 匯出數據
- 分享功能
- 主題切換
