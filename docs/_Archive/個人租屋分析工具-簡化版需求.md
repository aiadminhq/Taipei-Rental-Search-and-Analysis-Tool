# 個人租屋分析工具 - 簡化版需求文檔

**版本**: 個人版 1.0  
**開發時間**: 8小時  
**部署時間**: 30分鐘  
**目標**: 個人租屋決策輔助工具

---

## 🎯 產品概述

### 核心價值
一個專為個人租屋者設計的 AI 分析工具，幫助快速評估房源價值，避免租屋陷阱。

**主要功能**：
- 🔗 **URL 分析**：貼入 591 等網站連結，自動分析房源
- 📷 **截圖識別**：上傳房源截圖，AI 自動提取資訊
- 🔍 **智能搜索**：根據條件批量搜索符合需求的房源
- 🤖 **AI 評分**：110 分制智能評分和具體建議
- 📱 **手機優化**：響應式設計，隨時隨地使用

### 目標用戶
- **首次租屋者**：缺乏經驗，需要客觀評估標準
- **忙碌上班族**：時間有限，需要快速篩選工具
- **一般民眾**：希望有簡單易用的租屋輔助工具

## 🚀 核心功能

### 1. 多元輸入方式

#### URL 連結輸入
- **支援網站**：591、樂屋網、好房網等主流租屋平台
- **批量處理**：可同時貼入多個連結，批量分析
- **自動識別**：自動判斷網站類型，使用對應解析策略

#### 截圖上傳識別
- **拖拽上傳**：支援拖拽或點擊上傳
- **相機拍攝**：手機可直接拍攝房源資訊
- **AI 識別**：使用 Gemini Pro 2.5 提取關鍵資訊

#### 智能搜索（可選）
- **條件設定**：預算、房型、區域、特殊需求
- **批量結果**：一次搜索返回 15-20 個相關房源
- **自動分析**：搜索結果自動進行 AI 分析

### 2. AI 智能分析

#### Claude 評分系統
- **110 分制**：價格(25分) + 設備(40分) + 位置(20分) + 加分項(15分) + 寵物友善(10分)
- **適合度評語**：非常適合/很適合/適合/尚可考慮/需要評估/不適合
- **優勢分析**：列出房源的主要優點（最多3個）
- **風險提醒**：指出潛在問題和注意事項
- **行動建議**：具體的下一步建議

#### 分析內容
```
評分範例：
🏠 台北市大安區套房
💰 租金：18,000元/月
⭐ 評分：85分 (很適合)

✅ 主要優勢：
- 近捷運站，交通便利
- 設備齊全，拎包入住
- 價格合理，性價比高

⚠️ 注意事項：
- 樓層較低，採光一般
- 周邊停車不便

💡 建議：建議盡快預約看房，這個價位在大安區很難得
```

### 3. 資料管理

#### 本地存儲
- **IndexedDB**：使用瀏覽器本地資料庫
- **離線使用**：無網路時也能瀏覽已分析房源
- **隱私保護**：資料不上傳到伺服器

#### 基本功能
- **收藏系統**：標記喜歡的房源
- **篩選排序**：按評分、價格、時間排序
- **搜索功能**：在已分析房源中搜索

#### 資料匯出
- **JSON 格式**：完整的分析資料
- **CSV 格式**：適合 Excel 開啟
- **選擇性匯出**：僅匯出收藏或高分房源

## ⚙️ 技術實現

### 技術棧
- **前端**：React + Tailwind CSS + Alpine.js
- **後端**：Node.js + Express
- **AI 服務**：Claude API + Gemini Pro 2.5 API
- **存儲**：瀏覽器 IndexedDB
- **部署**：Replit

### API 整合

#### Claude API
```javascript
// 分析房源資料
const analyzeProperty = async (propertyData) => {
  const prompt = `
  作為專業房源分析師，請分析以下房源：
  ${JSON.stringify(propertyData)}
  
  請提供 JSON 格式回應：
  {
    "score": 85,
    "suitability": "很適合",
    "highlights": ["近捷運站", "設備齊全"],
    "concerns": ["價格偏高"],
    "recommendation": "建議盽快預約看房"
  }
  `;
  
  return await claude.complete(prompt);
};
```

#### Gemini Pro 2.5 API
```javascript
// 圖片識別
const analyzeImage = async (imageFile) => {
  const request = {
    contents: [{
      parts: [
        { text: "請提取這張房源圖片中的所有資訊" },
        { inlineData: { mimeType: imageFile.type, data: base64Image } }
      ]
    }]
  };
  
  return await gemini.generateContent(request);
};
```
