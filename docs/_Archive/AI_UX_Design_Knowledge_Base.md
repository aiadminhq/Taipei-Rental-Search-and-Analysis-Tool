## 🎯 核心概念與工具

### 主要 AI 設計平台
- **UX Pilot AI** - 主要設計生成平台
  - 網址：https://uxpilot.ai/a/ui-design
  - 功能：線框圖、高保真設計、組件生成
  - 特色：Figma 整合、自動流程生成

### 設計模式分類
1. **線框圖 (Wireframes)**
   - 低保真度結構設計
   - 專注於版面配置和功能架構
   - 適合初期概念驗證

2. **高保真設計 (Hi-fi Design)**
   - 完整視覺設計
   - 包含顏色、字體、圖像
   - 接近最終產品外觀

3. **組件設計 (Component Design)**
   - 可重複使用的 UI 元素
   - 系統化設計方法
   - 提升設計一致性

## 🖼️ 線框圖設計流程

### 基本操作步驟

#### 1. 環境設置
```
1. 前往 https://uxpilot.ai/a/ui-design
2. 選擇 "wireframes" 模式
3. 選擇 "desktop" 版型（推薦）
4. 準備設計提示內容
```

#### 2. 提示撰寫策略
**基礎提示範例：**
```
設計一個電商網站首頁線框圖，包含：
- 導航欄
- 主要橫幅區域
- 產品分類
- 特色商品展示
- 購物車功能
```

**進階提示技巧：**
- 每次僅選擇一個螢幕進行生成
- 提供具體的業務需求和目標用戶
- 明確指出重要的互動元素
- 考慮資訊層級和視覺重點

#### 3. 迭代優化方法
1. **第一次生成**：使用簡單描述
2. **第二次優化**：添加"盡可能詳細"
3. **第三次完善**：加入"探索所有可能模組"

## 🎨 高保真設計方法

### 切換至高保真模式
1. 在介面中選擇 "Hi-fi" 模式
2. 保持與線框圖相同的基礎提示
3. 添加視覺風格指引

### 設計風格控制

#### 風格提示範例
```
視覺風格指引：
- 使用極簡輕量設計風格
- 採用無邊框設計理念
- 主色調：#3B82F6（藍色系）
- 次要色：#EF4444（紅色強調）
- 字體：現代無襯線字體
- 留白：充足的空間感
```

#### 詳細度控制提示
- **基礎詳細度**：`"創建一個現代化的設計"`
- **中等詳細度**：`"使用極簡風格，包含所有必要功能模組"`
- **最高詳細度**：`"盡可能詳細，探索所有可能的設計模組和互動元素"`

### 品牌一致性維護
1. **色彩系統**：定義主色、輔色、中性色
2. **字體系統**：標題、內文、註解字體
3. **間距系統**：統一的邊距和內距規則
4. **圓角系統**：一致的圓角大小

## ✏️ 設計編輯技巧

### A. 區段編輯 (Section Edit)

#### 操作步驟
1. **進入編輯模式**
   ```
   雙擊目標螢幕 → 進入詳細編輯模式
   ```

2. **選擇編輯區域**
   ```
   滑鼠懸停 → 識別預定義 AI 區域 → 點擊 "Edit"
   ```

3. **局部修改策略**
   - 僅修改特定組件
   - 保持整體設計一致性
   - 快速修正小問題

#### 適用場景
- 調整按鈕樣式
- 修改文字內容
- 更換圖片或圖標
- 調整色彩搭配

### B. 整體螢幕編輯 (Whole Screen Edit)

#### 使用時機
1. **整體風格調整**：需要改變整個頁面的視覺風格
2. **版面重構**：大幅調整版面配置
3. **新頁面生成**：基於現有設計創建新頁面
4. **修正重大問題**：解決版面錯誤或不協調

#### 操作方法
```
選擇目標螢幕 → 點擊 "Edit" 按鈕 → 輸入修改提示 → 重新生成
```

#### 編輯提示範例
```
修改提示：
"保持現有的功能架構，但改為深色主題設計，
強調科技感和專業性，加強視覺層次感"
```

## 🔄 設計流程生成

### 手動流程定義

#### 步驟規劃
1. **確定用戶旅程**
   ```
   註冊 → 瀏覽 → 選購 → 付款 → 確認
   ```

2. **螢幕清單**
   - 歡迎頁面
   - 註冊/登入
   - 主頁面
   - 產品列表
   - 產品詳情
   - 購物車
   - 結帳流程
   - 訂單確認

3. **連接邏輯**
   - 定義每個螢幕之間的導航關係
   - 確保用戶流程的合理性

### 自動流程生成 (Autoflow)

#### 功能特色
- 智能分析用戶需求
- 自動生成螢幕序列
- 維持設計一致性
- 優化用戶體驗路徑

#### 使用方法
1. 提供詳細的專案背景
2. 描述目標用戶群體
3. 說明主要業務目標
4. 讓 AI 自動生成完整流程

#### 提示範例
```
專案背景：
為年輕專業人士設計的健身追蹤應用程式

目標用戶：
25-35歲，注重健康的上班族

主要功能：
- 運動記錄
- 目標設定
- 進度追蹤
- 社群分享
- 營養建議

請生成完整的用戶流程設計
```

## 🧩 UI 組件開發

### 組件類型分類

#### 基礎組件
- **按鈕組件**：主要按鈕、次要按鈕、文字按鈕
- **輸入組件**：文字框、下拉選單、核取框
- **導航組件**：導航欄、分頁、麵包屑
- **反饋組件**：載入動畫、提示訊息、進度條

#### 複合組件
- **卡片組件**：產品卡片、用戶資訊卡片
- **表單組件**：登入表單、註冊表單
- **列表組件**：新聞列表、產品列表
- **模態框組件**：確認對話框、詳情彈窗

### 組件生成流程

#### 1. 單一組件生成
```
步驟：
1. 選擇 "Component" 模式
2. 描述組件功能和外觀
3. 指定組件狀態（正常、懸停、禁用）
4. 生成並優化
```

#### 2. 批量組件生成
```
提示範例：
"為電商平台設計以下組件：
- 產品卡片（包含圖片、標題、價格、評分）
- 加入購物車按鈕（主要、次要樣式）
- 價格標籤（原價、折扣價）
- 評星組件（1-5星評級）"
```

#### 3. 組件系統建立
1. **設計原則定義**
   - 一致性：統一的視覺語言
   - 可擴展性：支援未來功能擴展
   - 可訪問性：符合無障礙設計標準

2. **狀態管理**
   - Default（預設狀態）
   - Hover（懸停狀態）
   - Active（啟用狀態）
   - Disabled（禁用狀態）
   - Focus（聚焦狀態）

3. **變體設計**
   - 尺寸變體：Small、Medium、Large
   - 樣式變體：Primary、Secondary、Tertiary
   - 主題變體：Light、Dark

## 💡 提示工程最佳實踐

### 提示結構範本

#### 基礎提示結構
```
[設計類型] + [功能描述] + [風格指引] + [詳細要求]

範例：
"設計一個響應式的電商產品頁面，
採用現代簡約風格，
包含產品圖片輪播、詳細資訊、評價區域和推薦產品，
使用藍白色調，強調清晰的視覺層次"
```

#### 進階提示結構
```
專案背景：[業務目標和用戶需求]
設計要求：[功能需求列表]
視覺風格：[設計風格描述]
技術限制：[平台或技術要求]
參考靈感：[參考案例或風格]

範例：
專案背景：為年輕族群設計的音樂串流應用
設計要求：
- 專輯瀏覽和搜尋功能
- 個人化推薦
- 播放控制介面
- 社群分享功能

視覺風格：
- 深色主題為主
- 鮮豔的漸層色彩
- 大膽的字體設計
- 流暢的動畫效果

技術限制：適用於 iOS 和 Android 平台
參考靈感：Spotify 的現代化設計語言
```

### 提示優化技巧

#### 1. 具體化程度控制
- **低具體化**：適合探索性設計
  ```
  "設計一個購物應用的主頁面"
  ```

- **中具體化**：適合迭代優化
  ```
  "設計一個購物應用的主頁面，包含搜尋欄、分類導航、特價商品區域"
  ```

- **高具體化**：適合精確實現
  ```
  "設計一個購物應用的主頁面，頂部固定搜尋欄（白色背景），
  下方橫向滾動的分類導航（8個分類），
  主要區域顯示今日特價商品（3x2網格布局），
  底部為推薦商品列表（垂直滾動）"
  ```

#### 2. 上下文豐富化
```
錯誤範例：
"設計一個按鈕"

正確範例：
"為電商網站設計主要行動呼籲按鈕，
用於'加入購物車'功能，
需要在產品頁面中突出顯示，
採用品牌主色（藍色），
包含懸停和點擊狀態設計"
```

#### 3. 約束條件明確化
```
設計約束範例：
- 螢幕尺寸：桌面版 1440px 寬度
- 品牌色彩：僅使用公司標準色彩
- 無障礙要求：對比度符合 WCAG AA 標準
- 技術限制：避免複雜動畫效果
- 內容限制：文字內容需支援多語言
```

## 🚀 進階技巧與秘訣

### 設計一致性維護

#### 1. 設計系統建立
```
基礎設計令牌：
Colors:
  primary: #3B82F6
  secondary: #10B981
  accent: #F59E0B
  neutral-50: #F9FAFB
  neutral-900: #111827

Typography:
  heading-lg: 32px/40px, Bold
  heading-md: 24px/32px, SemiBold
  body-lg: 16px/24px, Regular
  body-sm: 14px/20px, Regular

Spacing:
  xs: 4px
  sm: 8px
  md: 16px
  lg: 24px
  xl: 32px

Borders:
  radius-sm: 4px
  radius-md: 8px
  radius-lg: 12px
  radius-full: 9999px
```

#### 2. 組件標準化
```
按鈕系統：
Primary Button:
  - 背景：主要品牌色
  - 文字：白色
  - 尺寸：高度 44px
  - 圓角：8px
  - 內距：16px 24px

Secondary Button:
  - 背景：透明
  - 邊框：1px 主要品牌色
  - 文字：主要品牌色
  - 其他尺寸同 Primary
```

### 批量設計生成

#### 1. 頁面系列生成
```
提示範例：
"為 SaaS 平台設計以下頁面系列，
保持一致的設計語言和布局結構：

1. 儀表板主頁（數據概覽、快速操作）
2. 專案管理頁面（專案列表、進度追蹤）
3. 團隊協作頁面（成員管理、權限設定）
4. 報告分析頁面（圖表展示、數據篩選）
5. 設定頁面（帳戶設定、偏好設置）

每個頁面都應包含統一的導航欄和側邊欄，
使用相同的色彩和字體系統"
```

#### 2. 響應式設計生成
```
多裝置提示：
"設計響應式的產品展示頁面，包含：
- 桌面版（1440px）：3欄式布局
- 平板版（768px）：2欄式布局  
- 手機版（375px）：單欄式布局

每個版本都要保持相同的資訊架構，
但調整排版以適應不同螢幕尺寸"
```

### 設計測試與驗證

#### 1. 可用性檢查清單
```
設計檢查項目：
□ 導航是否清晰易懂
□ 重要功能是否容易找到
□ 文字是否具備足夠對比度
□ 按鈕是否具備明確的視覺回饋
□ 表單是否提供清楚的錯誤訊息
□ 載入狀態是否有適當提示
□ 空狀態是否有引導資訊
```

#### 2. 設計一致性檢查
```
一致性檢查：
□ 相同功能的元素外觀是否一致
□ 間距系統是否統一應用
□ 色彩使用是否符合設計系統
□ 字體層級是否正確使用
□ 圖標風格是否統一
□ 圓角大小是否一致
```

## 🔧 常見問題解決方案

### 設計品質問題

#### Q1: 生成的設計過於簡單或缺乏細節
**解決方案：**
```
優化提示策略：
1. 添加"盡可能詳細"關鍵詞
2. 明確列出所需的功能模組
3. 提供具體的業務場景描述
4. 參考優秀設計案例進行描述

改進前：
"設計一個部落格網站"

改進後：
"設計一個科技部落格網站首頁，包含：
- 精選文章輪播區域
- 文章分類導航
- 最新文章列表（含縮圖、標題、摘要、發布時間）
- 熱門標籤雲
- 搜尋功能
- 訂閱電子報區域
- 社群媒體連結
採用現代簡約風格，重視內容的可讀性"
```

#### Q2: 設計風格不符合品牌要求
**解決方案：**
```
品牌風格控制：
1. 明確描述品牌個性（專業、親切、創新等）
2. 提供具體的色彩代碼
3. 指定字體風格偏好
4. 描述目標用戶群體
5. 參考競品或靈感來源

範例提示：
"設計符合年輕科技品牌的應用介面，
品牌個性：創新、友善、專業
主色調：#6366F1（現代紫色）
輔助色：#10B981（充滿活力的綠色）
字體風格：現代無襯線字體，清晰易讀
目標用戶：25-35歲的科技愛好者
參考風格：類似 Notion 的簡潔設計"
```

### 技術整合問題

#### Q3: Figma 整合出現問題
**解決方案：**
```
Figma 整合步驟：
1. 確認 UX Pilot 外掛程式已正確安裝
2. 在 Figma 中開啟 UX Pilot 面板
3. 登入相同的 UX Pilot 帳戶
4. 選擇要匯入的設計
5. 確認圖層結構完整性

常見問題：
- 圖層遺失：重新生成並匯出
- 字體問題：確認 Figma 中有對應字體
- 圖片遺失：檢查圖片連結有效性
```

#### Q4: 自定義資產無法正確載入
**解決方案：**
```
資產載入檢查：
1. 確認圖片網址可直接訪問
2. 檢查圖片格式（建議 PNG、JPG）
3. 確認圖片尺寸適當（建議不超過 2MB）
4. 測試圖片連結在瀏覽器中是否正常顯示

圖片託管建議：
- 使用穩定的圖片託管服務
- 避免使用有權限限制的連結
- 定期檢查連結有效性
```
