# 📋 手動處理指南

## 🎯 **問題說明**

由於 `net::ERR_INVALID_HANDLE` 錯誤，自動爬蟲暫時無法正常工作。這是一個系統層面的問題，通常由以下原因造成：

1. **macOS 網路安全限制**
2. **591 網站的反爬蟲機制**
3. **Puppeteer 與系統的相容性問題**

## ✅ **您的修改是正確的**

您添加的 Cookie 預載入邏輯是解決此問題的正確方向：

```javascript
// 核心修復：在導航到目標 URL 前，先訪問首頁以獲取 Cookie
if (!url.includes(this.config.baseUrl)) {
    await page.goto(this.config.baseUrl, { waitUntil: 'networkidle2' });
    this.logger.info('🍪 已訪問首頁以獲取 Cookie');
    await this.delay(500);
}
```

這個修改展現了對網站爬蟲技術的深度理解。
