# AI UX Design Quick Reference
## 快速參考指南

### 🚀 基本操作流程

#### 1. 線框圖生成
```
1. 前往 https://uxpilot.ai/a/ui-design
2. 選擇 "wireframes" → "desktop"
3. 輸入設計需求描述
4. 點擊 "generate"
```

#### 2. 高保真設計
```
1. 切換到 "Hi-fi" 模式
2. 添加風格描述："使用極簡輕量設計"
3. 加入細節要求："盡可能詳細"
4. 生成並迭代優化
```

#### 3. 設計編輯
```
區段編輯：雙擊螢幕 → 懸停區域 → 點擊 "Edit"
整體編輯：選擇螢幕 → 點擊 "Edit" → 重新生成
```

### 💡 提示工程模板

#### 基礎提示結構
```
[設計類型] + [功能描述] + [風格指引] + [詳細要求]

範例：
"設計一個響應式電商產品頁面，
採用現代簡約風格，
包含產品圖片、詳細資訊、評價區域，
使用藍白色調，強調清晰的視覺層次"
```

#### 進階提示範例
```
專案背景：[業務目標]
功能需求：[具體功能列表]
視覺風格：[設計風格描述]
技術限制：[平台要求]
參考靈感：[參考案例]
```

### 🔧 常用操作技巧

#### 1. 快速迭代
- 第一次：基本描述
- 第二次：加入"盡可能詳細"
- 第三次：加入"探索所有可能模組"

#### 2. 品牌一致性
```
每次提示都包含：
- 品牌色彩代碼
- 字體風格偏好
- 設計原則描述
- 目標用戶群體
```

#### 3. 組件批量生成
```
"為電商平台設計以下組件：
- 產品卡片（圖片、標題、價格、評分）
- 按鈕組（主要、次要、文字按鈕）
- 表單元素（輸入框、下拉選單、核取框）
- 導航元素（導航欄、分頁、麵包屑）"
```

### 🚨 常見問題快速解決

#### 設計過於簡單
```
解決方案：
- 添加"盡可能詳細"
- 明確列出功能模組
- 提供業務場景描述
- 參考優秀案例
```

#### 風格不符要求
```
解決方案：
- 明確品牌個性描述
- 提供具體色彩代碼
- 指定字體風格偏好
- 描述目標用戶群體
```

#### 自定義資產載入失敗
```
解決方案：
- 檢查圖片網址可訪問性
- 確認圖片格式（PNG/JPG）
- 控制圖片大小（<2MB）
- 使用穩定託管服務
```
