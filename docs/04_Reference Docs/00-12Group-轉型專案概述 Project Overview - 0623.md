# 12Group 轉型計劃書專案 | 12Group Transformation Project

## 📋 專案概述 | Project Overview

本專案包含 12Group 原生概念股份有限公司的完整數位轉型策略規劃，涵蓋 AI 導入、組織架構重組、技術升級、市場分析等關鍵領域。專案採用結構化管理方式，將所有相關文件按功能分類整理，便於查閱和維護。

This project contains the complete digital transformation strategy planning for 12Group Native Concept Co., Ltd., covering key areas such as AI implementation, organizational restructuring, technology upgrades, and market analysis.
