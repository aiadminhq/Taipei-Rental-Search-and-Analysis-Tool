# 專案文檔庫

歡迎來到智能房源分析平台的文檔中心。

## 🚀 專案總覽 (Project Overview)

本專案旨在打造一個由 AI 驅動的智能房源分析平台。透過整合 Claude 和 Gemini Pro 2.5，我們能夠提供從房源資料提取、智能評分到市場趨勢分析的全方位服務。系統採用手機優先的響應式設計，並以 Replit 實現快速部署，核心資料儲存於使用者本地，確保隱私安全。

## 🛠️ 技術棧概覽 (Tech Stack Overview)

- **前端**: React, Tailwind CSS, Alpine.js
- **後端**: Node.js, Express
- **AI 服務**: Claude API, Gemini Pro 2.5 API
- **資料庫**: Browser IndexedDB (本地存儲)
- **部署**: Replit
